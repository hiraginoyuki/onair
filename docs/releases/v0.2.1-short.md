Adds OpenAI Chat Completions to Anthropic Messages compatibility.
OpenAI Chat clients can now route to upstream `/v1/messages` backends
through the explicit `chat_completions_via_messages` marker.

## What's new

- New `chat_completions_via_messages` route/backend marker for
  OpenAI Chat -> Anthropic Messages compatibility.
- `chat_via_messages` is accepted as a config-load alias and
  canonicalized immediately to `chat_completions_via_messages`.
- Buffered Anthropic Messages responses are translated back to
  Chat Completions response shape.
- Anthropic Messages SSE streams are translated to Chat Completions
  streaming chunks, including text deltas, tool-call deltas, finish
  reasons, and `[DONE]`.
- `stream_options.include_usage` is accepted on Chat requests for this
  compatibility path. A final Chat usage chunk is emitted only when
  upstream Anthropic stream usage was actually observed.

## Compatibility

Existing configs keep working. The new path is opt-in and requires an
Anthropic Messages-capable backend plus an explicit
`chat_completions_via_messages` route exposure.
