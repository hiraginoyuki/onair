Alpha Boundaries

Included

Typed request, response, error, stream lifecycle, protocol headers, exact same-profile envelope replay, fidelity diagnostics, and cache-intent analysis.

Excluded

Routing, auth, retries, failover, generic HTTP forwarding, storage, prompt logging, tool execution, uploads, retrieval, and cache-hit prediction.

Checks

The alpha gate validates schemas and synthetic vectors, codec paths, replay and mutation behavior, opaque containment, cache reports, arbitrary SSE chunk partitions, all six directed typed conversions, and selected buffered OnAir parity. Live provider benchmarks are manual, dry-run by default, local-only, cap-controlled, and never CI or release gates.
